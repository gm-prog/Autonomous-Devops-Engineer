# Immutable build inputs (Phase 8.4.2-D §5) — COMMITTED DIGESTS ONLY.
#
# format: <source-name:tag> <sha256:64hex> <exported-env-key>
#
# The middle column is the authoritative, immutable identity of the
# external image. The workflow NEVER resolves a tag at dispatch time: it
# reads these digests, builds `<repository>@<digest>`, pulls and inspects
# exactly that reference and exports it under the given key
# (`python3 -m e2e.image_pins`, parser `e2e.helpers.parse_pinned_images`).
# Any missing, malformed or non-digest pin is a hard error — there is no
# sentinel value, no tag fallback and no compatibility mode, so the same
# commit can never consume a different external image tomorrow.
#
# The tag in column 1 is provenance only (where the digest was observed);
# the digest reference built from column 2 is the identity that is pulled.
# ORDER-SENSITIVE? no — the key column is authoritative.
